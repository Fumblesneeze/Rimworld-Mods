## Why

A pile of small discomforts should not by itself permit the same severe mood break as a major
personal tragedy. Independently specify Dubs Break Mod's thought-based severity limit while
preserving the game's mood pressure, ordinary candidate restrictions and actual break workflow.

## Owner

Exactly one owner: **Make Rimworld Great Again**, `fumblesneeze.megamod`, `mods/megamod`.
Target **RimWorld 1.7 beta**. Origin replacement, **S119/P2-48**, Dubs Break Mod by Dubwise,
package `Dubwise.DubsBreakMod`, Workshop1722398508.

## What Changes

- Limit ordinary mood-caused breaks by the strongest current mood-thought group, using the source
  defaults of−10/−15/−20 for minor/major/extreme severity. Keep grouping and actual modified effects.
- Allow a milder eligible break when mood demands more than thoughts support; no qualifying thought
  means no ordinary mood break. Preserve native mood timing, eligibility and relative selection weights.
- Keep the source's independent threshold controls and optional colonist-only scope, using the
  common global/save/Use-global settings model with consistent missing-key defaults and seven languages.
- Close the native ideological shortcut's ability to escape the selected ceiling; retain eligible
  ideological preference and ordinary lower-tier/anomalous fallback without duplicate random draws.
- Preserve non-mood/forced episodes, already-running states, native risk displays and final-straw
  messages. Compose current memory fading and later counselling directly with their owned features.
- Use one admitted implementation with minimal semantic target checks, native fallback and bounded
  per-patch startup diagnostics. No copied source cache, Harmony bundle or source package spoofing.

**Specification only.** The selected1.7 binary, public provenance, native differences and intentional
corrections are retained in [research](../../../mods/megamod/docs/refinement/2026-11-06-dubs-break-mod-research.md).
No gameplay, compatibility, save migration or live verification is delivered by this draft.

## Capabilities

### New Capabilities

- `megamod-thought-gated-breaks`: current thought-group severity ceiling, native candidate fallback,
  population scope, shared tuning, lifecycle/composition and safe provider admission.

### Modified Capabilities

None. S068 supplies current faded effects, S100 handles counselling after a break starts, and
S001 retains mood-based portrait indicators; none requires another feature's runtime patches.

## Impact

- Planned Harmony integration requires `brrainz.harmony`; do not copy the source's bundled assembly.
  This feature needs no XML patch or XML Extensions dependency of its own. Declare XML Extensions
  if later implementation introduces its operations. No required source mod or DLC.
- Ideology/Anomaly and compatible thought/break providers are optional, absent-safe inputs. The
  original provider, when selected, owns its behavior; disable this overlapping feature only.
- Reuse native thought groups and per-evaluation facts. No persistent pawn-thought cache, inventory
  index, new gameplay tab, per-pawn setting, save conversion or Gateway/other-product dependency.
