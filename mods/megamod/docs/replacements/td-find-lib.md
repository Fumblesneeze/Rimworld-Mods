## Intentional deviations and omissions

Correct hidden-health category/suggestion leakage, first-occurrence severity, pawn-policy category
meaning, incomplete copies/persistence, translated-label bindings, import lock bypass, edge clipping,
vacuous mech All, misleading undefined ratios and unsupported-clause broadening. Named defaults
missing from content require an explicit choice; unsupported per-part health rules stay unavailable.
Only available applies to short lists too. Finite bounds stay finite, visibly unbounded choices stay
unbounded, and exact foreign imports are never rounded into new examples.

Saved query data is not inherited configuration; the actual suggestion preference uses common
global/save/Use-global settings. Bill/query/entity choices remain contextual. No bottom tab is added;
debug/private/hidden inspection leaves ordinary menus and cannot drive production/hauling. The source
reflection prewarm setting and arbitrary executable member parity are deliberately omitted.

Examples are labeled by their observed predicates, with known-only implants and corrected binding
identity; source-specific thresholds are retained where specified. High-end skill/market sample
comparisons use explicit unbounded ends. No new scheduler, automatic alerts, action issuance, migration,
whole TD library removal guarantee or universal external-provider facade is included.
